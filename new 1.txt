итоговый проект по C#

Трекер финансов  
Учёт личных доходов и расходов с визуализацией.
Учёт доходов/расходов.  
Категории транзакций.  
Визуализация (графики, отчёты).  
Экспорт в CSV/Excel.  

типы сущностей:

Пользователи - свойства пользователя может быть самостоятельна

Счета пользователя должны быть у конкретного пользователя, не могут быть сами по себе

Системные Категории - помогают определить тип затрат, могут быть самостоятельными, так как работают для всех пользователей и любых транзакций с любых счетов

Пользовательские категории - принадлежат пользователю

Транзакции - должны зависеть от определенного счета и категории

Тэги - принадлежат пользователю, нужны для удобства отображения

Бюджеты - должны зависеть от конкретного пользователя и могут не зависеть от остального

Цели накопления - должны зависеть от конкретного пользователя и могут не зависеть от остального

Запланированные транзакции/напоминания  - должны зависеть от определенного счета и категории

связи между типами сущностей:
1 пользователь - много счетов
1 пользователь - много бюджетов
1 пользователь - много целей накопления
1 пользователь - много тегов
1 счет - много транзакций
1 счет - много запланированных транзакций
много тегов - много транзакций
много тегов - много запланированных транзакций
1 категория - много транзакций
1 категория - много запланированных транзакций

свойства для сущностей:
Пользователи	
	id - автозаполняемое уникальное значение для поиска и работы с пользователем
	Имя - Визуализация при выборе пользователя
	Пароль - защита при попытке получить доступ, хешировать?
	Email - способ об восстановления пароля
	
Счета пользователя
	id - автозаполняемое уникальное значение для поиска и работы со счетом
	UserId - автозаполняемое значение текущим пользователем, связь с пользователем
	Имя - название счета
	Тип счета - дебетовый, кредитный
	Баланс - значение состояния счета
	Валюта - сейчас вроде не нужна, можно оставить на будущее
	Кредитный лимит - если счет кредитный, то проверять по лимиту сколько осталось и можно ли тратить еще
	Состояние счета - открытый/закрытый, вроде не сильно нужная информация, но можно добавить на будущее
	Описание
	
Категории
	Id - автозаполняемое уникальное значение для поиска и работы с категорией
	UserId — если категория пользовательская, иначе NULL
	Имя - визуальное отображение 
	Тип категории - системная или пользовательская, определяется автоматически
	Вид категории - Входящие или исходящие
	Описание - дополнительные данные, которые помогут выбрать нужную категорию
	
Транзакции
	Id - автозаполняемое уникальное значение для поиска и работы с транзакцией
	AccountId — счет списания или зачисления
	CategoryId - необязательное поле, помогает определить для чего произошла транзакция
	Сумма - точное значение, на которое должен уменьшиться или увеличится баланс счета
	Тип транзакции - приход или расход
	Дата и время транзакции - необязательно сейчас, но может быть полезно для анализа
	Описание - необязательное поле, но иногда его хочется заполнять для анализа
	Тег - для более удобной и точной визуализации, много значений Промежуточная таблица
	
Теги
	Id - автозаполняемое уникальное значение для поиска и работы с тегами
	UserId — принадлежит конкретному пользователю
	TransactionId - чтобы можно было найти все транзакции по определенному тегу. Промежуточная таблица
	Имя - визуальное отображение

Бюджеты
	Id - автозаполняемое уникальное значение для поиска и работы с бюджетами
	UserId - принадлежит пользователю
	Начало периода бюджета - нужно для понимания начальной границы планирования
	Конец периода бюджета - Нужно для понимания конечной границы планирования
	Коллекция значений Дебет:
		Категория - Обозначение откуда придут средства например зарплата или остаток с прошлого месяца
		Сумма - точное значение сколько придет средств
		Описание - для более точного понимания для будущего анализа		
	коллекция значений кредит:
		План - лимит затрат для понимания сколько средств заложено
		Факт - сколько средств потрачено за период  бюджета
		Остаток - Вычисляемое значение Сколько средств осталось, может быть отрицательным, если произошел перерасход по категории
		Категория - может быть не обязательным (в этом случае отображаем как без категории)
	Общая сумма запланированных средств - вычисляемое значение всех плановых данных из коллекции
	Общая сумма затрат - вычисляемое значение всех затраченных данных из коллекции
	Общая сумма остатка - вычисляемое значение общего остатка, может быть отрицательным
	
Цели накопления:
	Id - автозаполняемое уникальное значение для поиска и работы с целями
	UserId - принадлежит пользователю
	AccountId - счет на котором будет происходить накопление
	Имя - визуальное отображение
	Описание  - для более подробного понимания
	Цель - точное значение суммы, которую надо накопить
	Дата к которой надо накопить - по сути дедлайн
	Осталось накопить - вычисляемое значение, для понимания сколько осталось до достижения цели

Запланированные транзакции/напоминания
	Id - автозаполняемое уникальное значение для поиска и работы сзапланированно транзакцией
	UserId - принадлежит пользователю
	AccountId - с какого счета планируется транзакция
	CategoryId - в какой категории будет транзакция, необязательно
	Сумма - точное значение будущей транзакции
	Дата выполнения - дата, когда надо выполнить транзакцию
	Описание - для более подробного понимания для чего эта транзакция
	Галочка выполнения - чтобы можно было увидеть что уже оплатили, что еще осталось

Правила Account
Имя счета обязательное
Два счета с одинаковым названием быть не должно
Тип счета изменить нельзя
Счет можно закрыть, в БД он не удаляется а помечается закрытым. Данные можно получить если посмотреть счет отдельно
Удалить счет нельзя
Нельзя использовать закрытый счет в бюджете
Нельзя использовать закрытый счет в транзакциях
Баланс не может стать отрицательным для любого счета

сценарий создать счет
	Вводим 	
		Имя 
		Тип счета - дебетовый или кредитный
		Баланс - если тип счета кредитный, иначе поле недоступно
		Валюта - значение по умолчанию Rub
		Кредитный лимит - если тип счета кредитный, иначе поле недоступно
		Состояние счета - открытый/закрытый
	Проверки
		Имя не пустое
		Тип счета не пустое
		Не пустой Баланс или значение не 0 если тип счета кредитный
		Баланс не пустой и автоматически равен 0 если тип счета дебетовый
		баланс не отрицательный
		Не пустая Валюта
	В БД
		Запись данных при нажатии на кнопку Сохранить
	Ошибки
		Не заполнено обязательное поле
	Система возвращает
		Сущность с данными из БД
